# Notification Sound Placeholder

## To add the "Ding" sound effect:

1. **Option 1: Download a free sound**
   - Search for "notification ding sound effect" online
   - Download a .wav file (short, ~1 second)
   - Rename it to `notify.wav` and place in this folder

2. **Option 2: Generate a simple beep**
   - The system will use a fallback system beep if notify.wav is not found

3. **Recommended sound characteristics:**
   - Format: WAV (uncompressed)
   - Duration: 0.5 - 2 seconds
   - Sample rate: 44100 Hz
   - Type: Short, attention-grabbing ding/ping

## The Live Display will:
- Play the sound when a new ticket is called
- Fall back to system beep if file not found
- Work without the sound file (silent mode)
